# 승률 엔진

포커 중계의 실시간 승률이 어떻게 계산되는지 보여주고, 같은 엔진으로 베팅 판단을 훈련하는 단일 HTML 페이지입니다.

- `index.html` — 앱 전체. **의존성 없는 단일 파일**입니다. 인터넷 없이도, 설치 없이도 동작합니다.
- `launch.command` — 로컬 런처.

## 로컬에서 열기

**바탕화면의 `승률 엔진` 앱을 더블클릭**하면 됩니다. 터미널도 서버도 뜨지 않고 브라우저에서 바로 열립니다.

앱은 이 폴더의 `index.html` 을 먼저 찾아 열기 때문에, 여기서 파일을 고치면 앱에도 그대로 반영됩니다. 폴더를 옮기거나 지우면 앱 안에 넣어둔 사본으로 자동 전환합니다 — 어느 쪽이든 열리지 않는 상황은 없습니다.

앱을 다시 만들려면 `index.html` 을 `~/Desktop/승률 엔진.app/Contents/Resources/` 에 복사하면 사본이 갱신됩니다.

`index.html` 을 직접 더블클릭해도 똑같이 동작합니다. 페이지가 완전히 자족적이라 `file://` 로도 전부 동작합니다.

런처를 쓰면 로컬 서버로 띄우고 브라우저까지 열어 줍니다.

```bash
./launch.command
```

Finder 에서 `launch.command` 를 더블클릭해도 됩니다. 빈 포트를 8777부터 찾아 쓰고, 끄려면 터미널에서 `Ctrl-C` 를 누르면 서버가 정리됩니다. `python3` 이 없으면 파일을 직접 여는 방식으로 자동 전환합니다.

## 휴대폰에서 열기

같은 와이파이에 있는 휴대폰에서 보려면:

```bash
./launch.command --lan
```

터미널에 `http://192.168.x.x:8777/index.html` 형태의 주소가 찍힙니다. 휴대폰 브라우저에 그 주소를 입력하면 됩니다.

`--lan` 은 **같은 네트워크의 다른 기기에 이 폴더를 열어 줍니다.** 카페나 공용 와이파이에서는 쓰지 마세요. 끝나면 `Ctrl-C` 로 끄면 됩니다.

## 다른 사람에게 공유하기

**파일 하나만 보내면 됩니다.** `index.html` 을 AirDrop·메일·메신저로 보내면 받는 쪽에서 더블클릭만으로 열립니다. 서버도, 인터넷도, 설치도 필요 없습니다. 외부 요청을 전혀 하지 않는 페이지라 회사 노트북에서도 그대로 열립니다.

공개 URL 이 필요하다면 이 파일 하나를 정적 호스팅에 올리면 끝입니다 — GitHub Pages 저장소에 `index.html` 로 넣거나, Netlify Drop 같은 곳에 끌어다 놓는 식입니다. 빌드 과정이 없습니다.
